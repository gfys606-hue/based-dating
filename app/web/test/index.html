Install it

  1. Tap Download for Android.
  2. Open the downloaded file. If Android asks, allow your browser to install unknown apps.
  3. Tap Install, then open Based and log in with your email.

Getting "App not installed" on an update? Uninstall the old Based test app first, then install again.
